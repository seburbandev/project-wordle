# Word Game

## Joy of React, Project I

In this project, I recreated a popular online word game, Wordle:

![Demo showing the finished product, our Wordle clone](docs/wordle-demo.gif)

In Wordle, users have 6 attempts to guess a 5-letter word. You're helped along the way by ruling out letters that aren't in the word, and being told whether the correct letters are in the correct location or not.

## First Attempt

This is my first attempt implementing it. I'm well aware there are areas for improvement. In this attempt I was focusing on "getting it working" without overthinking or over-engineering the solution. Other branches contain my subsequent attempt that improve my initial solution.
